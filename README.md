# Kippet

Kippet 是用 SwiftUI 和 AppKit 写的 macOS 剪贴板管理器，支持 macOS 14 及以上。

## 使用

应用显示名为 Kippet（拾贴）。菜单栏用单色小标签标记，应用图标是青绿底上的剪贴卡片，挂着一枚写着 K 的琥珀色标签，意思是「替你留着」。图标源文件在 `Resources/IconSource/Kippet.svg`。

打开 `dist/Kippet.app`，从菜单栏的标签图标或默认快捷键 `⌥⇧V` 打开底部抽屉。复制文字、链接、图片或文件后，可以组合使用关键词、内容类型和来源应用筛选，也可以点击卡片上的应用图标来筛选。文件条目保存原文件位置，带图片快照的条目也能从历史回贴图片。

窗口在屏幕底部横向展示卡片。打开面板后可以用方向键选卡，按空格预览，再用方向键切换预览。直接输入或按 `⌘F` 可搜索。编辑搜索时，左右键移动光标，上下键选择结果。

- 系统语言为英文时，Kippet 界面显示英文。
- 按回车粘贴选中项。`⌘1` 到 `⌘9` 可快贴当前筛选列表中的前九项。按住 `⌘` 会高亮卡片角标。
- `⇧↩`、`⇧⌘` 加数字可将文字或链接粘贴为纯文本。系统截图快捷键可能优先占用 `⇧⌘3`、`⇧⌘4`、`⇧⌘5`，可改用 `⇧↩`。
- 在卡片区按 `⌫` 删除，按 `⌘Z` 或点击「撤销删除」恢复。`⌘S` 切换星标，`⌘←` 和 `⌘→` 在历史、全部收藏和分组之间切换。
- 动效统一为一套节奏：方向键选卡、按下等反复操作最快，打开面板时前排卡片依次升起，切换钉板时卡片一起落位。预览里按 `←` `→` 翻页，内容顺着按键方向滑入。面板收起途中再次呼出会从当前位置接着升起。系统开启「减少动态效果」后，所有位移都换成淡入淡出。
- 底部提示分两种：成功打勾，几秒后自动淡出；失败或需要你操作的显示橙色提示，停留更久。
- 普通鼠标滚轮可横向移动卡片。点击面板外部会收起面板，点工具栏图钉可暂时保持显示。
- 按住 `⌘` 点击可增减多选，按住 `⇧` 点击可选一段卡片。选中的文字和链接可按当前列表顺序用换行或空格拼接，再贴回原输入框。
- 选中卡片后可加入「粘贴栈」，也可以在栈里打开「连续收集」。回到输入框按 `⌃⌥V` 贴下一条，或者点栈里的「贴下一条」。栈支持调整顺序、移除和恢复上一条，本次运行结束后会清空。系统 `⌘V` 仍可正常粘贴剪贴板。

如果 macOS 首次提示允许 Kippet 读取剪贴板，允许后再复制一条内容即可开始记录。也可以在「系统设置 → 隐私与安全性 → 剪贴板」调整授权。

- 新安装首次打开会显示使用引导，查看当前呼出快捷键和授权状态。也可从菜单栏再次打开「使用引导…」。
- 在目标输入框里按 `⌥⇧V`，历史面板会暂时接收按键，原应用继续保持前台。授权辅助功能后，按回车或双击卡片会写回剪贴板，并在面板关闭、目标焦点确认后发送 `⌘V`。如果中途换了应用或输入框，可以回到目标位置重新打开 Kippet。
- 回车时如果提示需要授权，可以请求系统授权，也可以选择返回原应用手动粘贴。首次从临时签名切换到 Developer ID 时，需要给新的应用身份授权一次。如果系统设置里旧条目仍在，请在「隐私与安全性 → 辅助功能」（macOS 27 为「设备控制与数据访问」）移除旧条目，再添加当前的 `dist/Kippet.app`。
- 右键文字或链接可粘贴为纯文本。
- 右键或从底部菜单选择「处理后粘贴」，可整理空白、格式化 JSON、清除链接追踪参数等。也可以按 `⌥↩` 打开列表，输入名称筛选，用方向键选择，按回车粘贴或按 `Esc` 关闭。上次使用的处理方式显示在列表首位。
- 文字卡片的「粘贴为」菜单可选择原格式、纯文本、Markdown 或 HTML 源码。转换后的 Markdown 和 HTML 源码以纯文本粘贴。
- 单个 JPG、PNG 或 TIFF 文件可以作为图片贴进对话框。剪贴板同时提供文件地址和图片时，Kippet 会把两者保存到同一张卡片。需要文件地址时可右键选「复制原文件」。旧记录如果只指向受保护的微信临时文件，可右键「选取图片文件…」并选择原图或另存的图片。Kippet 会把图片补存到原卡并复制到剪贴板。
- 点击钉板栏的 `+` 新建带颜色的钉板，右键钉板可改名、改色或删除。右键卡片或将卡片从右上角拖到钉板即可归类，同一项可以加入多个钉板。删除钉板后，里面的卡片仍可在收藏中找到。
- 面板打开时按 `⌘N` 新建片段，输入多行正文或单个网页链接，可填写标题并存入全部收藏或指定钉板。也可从菜单栏选择「新建片段…」。
- 用底部「多选」逐张选卡，也可在卡片区按 `⌘A` 全选当前结果。用「归入钉板」一次加入所选卡片。用钉板标签右侧的拖拽手柄可排序钉板。在钉板里，将卡片右上角的拖拽手柄拖到另一张卡片的位置可调整板内顺序。各钉板的顺序独立保存。
- 右键卡片可添加可搜索的备注。文本预览支持编辑正文、保存或保存并粘贴。修改正文时会重新按纯文本保存。
- 颜色卡片显示色块，预览和右键菜单可复制 HEX、RGB、HSL 或 SwiftUI Color。
- 代码卡片显示语言和语法高亮，按空格可滚动查看完整代码。
- 验证码卡片会突出显示验证码，右键可选择「只复制验证码」。
- 工具栏可单独筛选颜色、代码和验证码。
- 单独复制的邮箱和号码会显示联系卡片，可点击图标或从右键菜单发邮件、拨打。
- 已保存到历史的图片会在后台用系统 Vision 识别中文和英文，识别结果留在本机，可搜索或右键提取文字。链接预览只在点「加载链接预览」后访问该网页，并在本次运行内缓存。
- 图片中的二维码内容会在本机识别。卡片显示二维码标记，可按内容搜索，右键可复制内容或打开其中的网页链接。
- 用卡片右上角的拖拽手柄拖出文字、图片或文件。图片可导出为文件，普通文件依赖原路径。
- 在「设置 → 快捷键」可以分别录制呼出 Kippet、粘贴栈贴下一条、聚焦搜索和新建片段的组合键。点击当前组合键开始录制，按 `Esc` 取消。每项均可单独恢复默认。
- 从「设置」可调整登录时启动、历史保留、来源应用排除和复制提示音。应用排除依据前台应用，启用排除规则时也会跳过检测到来源不稳定的变更。
- 在「设置 → 通用」可手动检查更新。「自动检查更新」默认关闭，开启后在启动或打开设置时检查，每 24 小时最多自动检查一次。更新检查是 Kippet 仅有的联网点之一，只从 GitHub 获取最新发布信息，不发送剪贴板历史或设备数据。
- 在「设置 → 规则」可按来源、内容类型、识别类型、包含文字或正则匹配新复制的内容，自动归入钉板、加星标、到期删除或跳过记录。规则可启停、拖动排序和删除。右键卡片可从当前来源和内容类型新建规则。
- 默认跳过常见密码管理器的复制内容，识别出的验证码 2 分钟后删除。到期卡片会显示倒计时，最后 15 秒变为橙色。加星标或归入钉板可取消到期删除。
- 「颜色归入『颜色』钉板」默认关闭，开启时会使用已有「颜色」钉板，缺少时会创建一个。
- 在「设置 → 自动化」开启本机 MCP 读取，复制 Claude Desktop、Claude Code 或 Cursor 的配置。AI 工具可查历史和钉板，读取时会排除验证码、定时删除的卡片和被跳过的来源，图片只提供元数据。另行开启「允许 AI 新建片段」后，AI 工具可向正在运行的 Kippet 发送片段。
- 在每台 Mac 的「设置 → 同步」选择同一个云盘文件夹。Kippet 会在其中的 `Kippet Sync` 同步收藏、钉板、片段、卡片备注、图片和排序。普通历史和有过期标记的卡片留在本机，文件卡片只同步原路径和已有的图片快照。
- 图钉旁会显示同步状态。「设置 → 同步」可查看上次同步时间和其他设备，也可以立即同步或停止同步。停止同步后，本机记录和同步文件都会保留。
- 快捷指令可用「打开 URL」调用设置中可复制的 `kippet://` 链接，也可在 Raycast 或 Alfred 使用。这些链接可打开面板、填入搜索词、打开粘贴栈或预填片段编辑表单。另行开启「允许链接复制历史」后，`kippet://copy?index=1` 可把最新的历史条目放到剪贴板。
- 从更多操作可以随时暂停记录。Kippet 跳过带机密或临时标记的内容，复制其他敏感信息前可以手动暂停。
- 屏幕或系统休眠、锁屏、切换用户会话或暂停记录时停止轮询剪贴板，恢复后立即检查一次。
- 从 ClipShelf 版本升级时，先退出旧版，再打开 Kippet。首次启动会把历史文件夹、设置和同步文件夹搬到新名字下，旧的 `clipshelf://` 链接仍然可用。应用身份变了，需要重新允许读取剪贴板和辅助功能，「登录时打开」也要重新打开一次。
- 历史和分组逐条保存在本机的 `~/Library/Application Support/Kippet/History.sqlite3`。从旧版升级会在首次启动时导入 `History.plist`，原文件保留为迁移前的备份。
- 图片原图按需从本机历史读取，减少常驻内存。历史超过 2,000 条时，可用的全文索引会加速搜索，结果和排序保持一致。
- 普通历史默认最多 1,000 条，最大占用 64 MiB。可在设置中调整条数或保留天数。收藏另有 32 MiB 空间，单条记录上限为 8 MiB。清空历史会保留星标和钉板收藏。

## 构建

本机有 Apple 下载的 Developer ID Application 证书和配套私钥时，先在项目根目录运行一次。脚本导入公有证书，并把构建选用的指纹保存在本机项目配置中。

```sh
bash Scripts/configure-signing.sh /path/to/developerID_application.cer
```

后续构建复用该签名。也可以用 `KIPPET_SIGN_IDENTITY` 指定本机钥匙串里的签名身份。

```sh
./Scripts/build-app.sh
```

## 发布

对外分发要打成 Apple 芯片和 Intel 通用包，并经过 Apple 公证，这样别人下载后双击就能打开。先存一次公证凭据（会提示输入 App 专用密码）：

```sh
xcrun notarytool store-credentials kippet-notary --apple-id <Apple ID> --team-id <Team ID>
```

然后构建通用包，再签名、公证并打成 DMG：

```sh
./Scripts/build-app.sh --arch arm64 --arch x86_64
./Scripts/package-release.sh
```

DMG 输出到 `dist/release/Kippet-<版本>.dmg`，同时复制到 `site/downloads/Kippet.dmg`。DMG 里的应用名为 `Kippet.app`。

发布到 GitHub 时，把 DMG 以带版本号和不带版本号的两个名字都上传到 Release：

```sh
cp dist/release/Kippet-<版本>.dmg /tmp/Kippet.dmg
gh release create v<版本> dist/release/Kippet-<版本>.dmg /tmp/Kippet.dmg --title "Kippet <版本>"
```

- [Kippet 官网](https://kippet.mindmesh.site/) 有中文和[英文](https://kippet.mindmesh.site/en/)两版，下载按钮指向 GitHub Releases 的最新 DMG。非中文浏览器首次访问会进入英文版，切换语言后会记住选择。

修改 `site/` 后运行 `./Scripts/deploy.sh` 发布官网。脚本通过 SSH 上传中英文页面及静态素材，校验后切换 `sense:/opt/projects/kippet/current`，保留旧版本并核对公网文件。`./Scripts/deploy.sh --dry-run` 可查看发布目标。

域名入口由 Cloudflare Zero Trust 中 `sense-tunnel` 的已发布应用路由管理。安装包通过 GitHub Releases 发布。

运行 `swift test` 可验证捕获、搜索、收藏、持久化和直接粘贴的焦点校验。剪贴板测试使用独立的命名剪贴板。

在「控制台」里搜索子系统 `com.fieai.kippet` 和消息 `Stack attempt=`。同一个编号关联入口、焦点确认、发键和出队，`before` 与 `after` 是队列条数。
